# Carte 3D : trois directions de rendu

Maquettes autonomes : même carte, mêmes tâches, trois styles. Elles ne sont pas branchées sur Nexora.

| Direction | Rendu | Esprit |
|---|---|---|
| A · Diorama doux | `rendu-A.png` | Façon Dorfromantik : falaises en strates, tuiles biseautées, bosquets, toits de tuiles, écume, lumière dorée, effet miniature marqué. |
| B · Pastel architectural | `rendu-B.png` | Façon Townscaper : maisons hautes aux teintes pastel du projet, fenêtres cintrées, liseré encré fin, ciel de matin. |
| C · Cartoon vivant | `rendu-C.png` | Façon Animal Crossing : ombrage en 3 tons, contours épais, formes rondes, monde courbé. |

Ouvrir `index.html?d=A` (ou `B`, `C`) dans un navigateur : three.js 0.158 est chargé depuis cdn.jsdelivr.net, la scène est animée (fumées, flammes, grues, portails, feuillages).
