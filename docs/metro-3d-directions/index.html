Le réseau du temps

Chaque projet est une ligne, chaque tâche une station. La distance entre deux stations suit exactement l'écart entre leurs dates : une semaine mesure toujours la même longueur. Le train de chaque ligne est arrêté sur aujourd'hui ; les prochaines stations sont devant lui. Quatre façons de parcourir le même réseau.

    Grammaire du réseau

    Ce qui ne change pas

    • Même grammaire que la Vue Métro 2D : ligne = projet, bifurcation = action longue, losange = jalon, correspondance = dépendance entre projets.
    • Échelle de temps linéaire et commune à toutes les lignes. Une station est posée à son échéance.
    • Le train de chaque ligne marque aujourd'hui. Le tronçon déjà parcouru est grisé.
    • Le tableau « Prochains départs » liste les huit prochaines échéances, retards en tête. Un clic amène la caméra sur la station.
    • La fiche permet de passer à la station précédente ou suivante de la ligne, et de prendre une correspondance.
    • Lecture seule : rien ne modifie une tâche depuis le réseau.
